# EquipRent Server: The Engine Behind the Rentals

The backend API of **EquipRent**, a rental marketplace where equipment owners list their gear and customers browse, book, and rent it for a specific period. It handles equipment management, rental bookings, secure online payments, and administrative control.

> This repository contains the **backend** of the project. The frontend lives in a separate repository.
